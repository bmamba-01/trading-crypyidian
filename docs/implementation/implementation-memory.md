Fail-closed: Bất kỳ account enabled nào có snapshot missing, unknown, stale, future, mismatched as_of/currency hoặc observation FX thiếu/stale đều làm mẫu số không usable (`DENY_NEW_ENTRY` với reason code cụ thể).
