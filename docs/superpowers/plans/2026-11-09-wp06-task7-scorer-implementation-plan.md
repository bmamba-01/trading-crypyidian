## Goal and safety boundary

Produce a versioned scoring artifact calibrated only from authorized train/validation, an aggregate scorer-specific report for one-shot TEST evaluation, an immutable opportunity proof for the exact declared TEST universe, and a governed runtime `DISABLED`/`SHADOW`/`PAPER_GATE` path. `PAPER_GATE` stays closed until the TEST proof/report and separate owner/reviewer approval all bind to the same exact lineage. `SHADOW` cannot change decisions or execution side effects. No LIVE mode, exchange credentials, orders, reservations or training payloads in scorer/UI events.
